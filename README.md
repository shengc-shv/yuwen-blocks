# 方块语文 · 三年级上

给一个小学三年级上的孩子用的移动端语文练习网页。像素伙伴塔式进度、短回合练习、**答错复盘式巡查镜**、错题自动归档、断点续做与按天云端存档。

- 教材版本：**人教版（部编版）小学语文三年级上册 2026 秋版**，全册 8 单元，第 15 课《金色的草地》。
- 形态：纯静态前端（HTML/CSS/JS，无构建步骤），手机浏览器直接打开，可加到主屏幕。
- 数据：IndexedDB 本地为主（离线可用）＋ 云端每日一个存档（自动同步、换设备可恢复）。

> 内容与许可边界见 [NOTICE.md](./NOTICE.md)。仓库不含教材原文、插图或 PDF，不含任何商业游戏的名称、角色与专有物品名称。

## 为什么这样设计

注意力与粗心是两个会互相打架的目标：倒计时、连击提速、密集特效能让人更兴奋，却会让粗心的孩子错得更多。因此：

| 目标 | 做法 | 明确不做 |
|---|---|---|
| 保持连续注意力 | 每回合 3–5 题、单屏单题、答对就来一位像素伙伴、进度可见、中断可续不清零 | 倒计时、闪烁粒子、自动音效、弹窗、按用时排名 |
| 治粗心失分 | **答错才弹「巡查镜」复盘**：逐字高亮形近字/多音字，对照「你选的 vs 正确的」；答对直接过，不打断连对节奏 | 奖励「快」、错题只标「错了」、手工录错题 |
| 自动错题闭环 | 答错自动入集 → 分「看错了 / 记混了 / 还没学会」→ 1/3/7 天间隔回流 → 连对 2 次出集 | 让孩子或家长手抄错题 |
| 掌握度 | 每个知识点按最近 8 次作答加权，驱动伙伴塔与等级解锁 | 用打卡天数冒充掌握情况 |

## 界面与菜单

底部菜单固定次序：**练习 → 错题 → 地图 → 回忆录 → 存档**。

进度格不用方块，改用三位原创像素伙伴，做对一题就点亮一位：

| 形象 | 名字 | 配色 |
|---|---|---|
| 头顶两片小叶子的绿脸 | 苔苔 | 草绿 |
| 戴额饰的青灰脸 | 岩岩 | 石蓝 |
| 有小耳朵和圆鼻的粉脸 | 团团 | 樱粉 |

- **一趟练习的进度条**：5 个头像位，当前位金框、答对点亮、答错标红、未解锁灰显
- **伙伴塔**：20 格三种形象轮换，攒满升级，塔下列出名字图例
- 图形全部由 `index.html` 里 `<symbol>` 的矩形逐格绘制，造型与配色均为本项目原创，**不使用任何商业游戏的名称、角色或贴图**；仓库公开且站点已上线，这条边界必须守住
- 界面统一用「回忆录」指过往年级复习；内部 `past` / `grade` 判定逻辑不变，历史数据无需迁移

## 一趟练习怎么走

- **选范围**：练习页可选「第几单元 + 具体第几课」，也能选「整个单元」，不再写死某一课；本课题目不够时自动用本单元补齐并在页面提示。选择会记住，下次打开沿用。**单元与课文联动**：换单元时课文下拉只列本单元的课并自动跳到第一课；非法课号（旧数据 / 导入备份）会在数据层统一纠正。地图页「当前学到哪一课」同样处理。
- **断点续做**：做到一半自动存成一条待办（只存题号与进度），刷新页面、关掉浏览器、换设备回来都能「接着做完」，也能「放弃这一趟」。每个使用者各自一条待办，互不干扰。
- **一次点击走到底**：选完点「确认提交并继续」就到下一块，不再有「下一块」中转页；答对只给轻提示，答错才弹巡查镜复盘（含解析），关镜子时下一块已准备好，最后一题直接出结算。

## 答错之后：分层解析

解析不念答案。按公开教研里较一致的做法分六块（`js/explain.js` 生成，文案全部原创）：

| 块 | 内容 | 教研依据 |
|---|---|---|
| 错因诊断 | 顶部显示「看错了 / 记混了 / 还没学会」，三类各给一条不同对策 | 先挖错因再讲方法，别笼统说「粗心」 |
| ① 逐项排除 | **针对孩子实际选的那个选项**讲它为什么不对 | 选择题先排错再选对；干扰项逐一击破 |
| ② 正解回扣 | 正确答案为什么对 | 对比标准答案，把知识讲透 |
| ③ 考点定位 | 这题考的是什么 | 错题本三要素：错误原因 + 考点 + 答题技巧 |
| ④ 方法迁移 | 一句可复用的口诀 / 答题步骤 | 方法提炼、答题模板、形声字偏旁表义、病句三查 |
| ⑤ 遮住重做 | 自己再选一次，能讲出「为什么错」才算真会 | 变式巩固、遮住重做、当小老师讲一遍 |

模板按知识点细分（字音 / 多音字 / 字形 / 笔画 / 词义 / 量词 / 的地得 / 标点 / 病句 / 修辞 / 阅读 / 方法 / 文言 / 古诗顺序 / 诗句理解）；古诗按题干区分「背顺序」和「读懂诗句」，避免把理解题讲成背诵题。已移除原来对所有题都一样的三条通用 checklist，改成每题专属的关键词提示。

错题集里每行直接显示「考点 + 下次怎么想」，点「看完整分析」可回看完整解析，并一键遮住答案重做。解析只作为运行时字段挂在题目上，**不写进每日存档**，云端数据结构不变。

## 题库维度

三上按「课文 × 维度」组织，26 课每课至少 6 题：

| 维度 | 题型举例 |
|---|---|
| 拼音与字音 | 选正确读音、常见误读辨析 |
| 生字生词 | **形近字选字填空**、近义词辨析 |
| 句子运用 | 的地得、关联词、标点、病句、修辞（每课一道独立题，不复用题干） |
| 阅读理解 | 自编概述题；干扰项是「看似合理的错误理解」，不用一眼假的凑数项 |
| 背诵积累 | 古诗上下句与诗句理解（仅古诗课，公有领域作品） |
| 文体与方法 | 每单元一道：预测、观察、中心句、时间顺序、文言文等 |

专项复习可按维度整组练，也可按细知识点练；练习页每题标出所属维度与知识点。答案位置按课号轮转，不会永远是 A。

**题目出处**：题卡顶部明确显示「第 N 课《课题》· 第 U 单元」，巡查镜里同样标出；生成题的题干自带《课题》· 前缀。回忆录题则标明年级册次。

**干扰项质量约定**（见 `js/question-bank.js` 顶部注释）：
- 生字题一律用形近/同音的**单字**做干扰项（如「蒲公英」→ 蒲 / 铺 / 捕 / 浦），必须辨字形字义，不能靠「找含目标字的词」秒选
- 阅读与方法题的干扰项必须是 plausible 的替代理解或替代做法
- 全库题干不重复；同课其他题不得泄露该课阅读题的答案
- 题号（ID）保持稳定，历史错题与待办不会因题库改版而断链

**内容边界**：拼音与生字用词标范围内的常见字词，句子、例句、阅读题全部原创编写，背诵只取公有领域古诗；不含教材课文原文、生字表原表、插图或段落。按课素材在 `js/bank-data.js`，生成器在 `js/question-bank.js`，增补题目只需加素材数据。

## 本地运行

```bash
cd yuwen-blocks
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。本地域不在云服务白名单内，**云端同步会显示「待同步」，练习与本地存档照常可用**——这是预期行为，不是故障。

## 云端每日存档

- 表：`daily_saves(space_id TEXT, save_date DATE, payload JSONB, …)`，`UNIQUE(space_id, save_date)`。
- 每次结算生成一份当日快照，按 `space_id + save_date` 覆盖式上传（一天一个存档，同一天反复练习只会更新当天那份）。
- **日期一律按北京时间 `Asia/Shanghai` 计算**，全局常量 `YW_TZ`，不用抓取时间、不用系统时区兜底。
- 存档内容只有：日期、题号、对错、错因分类、知识点编号、掌握度、当日统计、进度单元。无姓名、邮箱、照片、录音。
- 首次打开生成一串随机「存档码」（`space_id`）。在「存档」页复制它，换设备粘贴即可恢复全部历史。
- 同步失败会标为「待同步」并保留在本地，下次启动自动重试；不会静默丢数据。

**安全取舍（请知悉）**：本项目不含登录体系，云表允许匿名读写（RLS 为 `USING (true)`），靠每个使用者一串不可猜的随机存档码区分。存档里只有题号、对错、错因、知识点编号和统计，无姓名、照片、录音；使用者昵称只存在本机。存档码等同于钥匙，**不要公开分享**。若要面向不特定公众开放，需改成真正的账号登录 + 按身份 RLS。

## 多个使用者

不需要账号、邮箱、密码或验证码。顶栏点当前名字打开「今天谁在练？」，新建使用者只要起个名字，切换一下就是一份全新且独立的档案。

- 每个使用者独立：错题集、知识点掌握度、当前进度、方块等级、连续天数、每日存档。
- 云端 `space_id` = 使用者 ID，`UNIQUE(space_id, save_date)` 保证「一人一天一份」，不会互相覆盖。
- 换设备：在「存档」页复制该使用者的存档码，粘贴回去即可读回云端记录。
- 本地旧版单用户数据会在首次启动自动迁成第一个档案，历史不丢。

适合一个孩子先用、以后 2–3 个好朋友一起用的小范围场景。

## 换设备与同步

**同步认码不认名**：名字相同不等于同一个使用者，身份是每人一串随机存档码。

- **新设备第一次打开**：自动检测云端已有存档并弹出选择面板，点一份就接着用；方块、错题、掌握度、「今天挖第几课」和每日统计一起恢复。
- **手动方式**：在「存档」页复制存档码 → 新设备粘贴 → 自动恢复；本机已有记录时会先确认是否覆盖，不静默覆盖。
- 每次答题都会自动上传当天快照；「存档」页另有「立即上传今天」「从云端刷新进度」，并显示最近同步时间、待同步份数与最近错误。
- 本地始终先存一份；同步失败标「待同步」，下次打开自动重试，不会静默丢数据。

**已知限制**：同一天两台设备用同一存档码时，最后一次上传会覆盖当天那份（没有逐题合并与冲突提示）。目前适合一台设备为主、偶尔换设备接着用的场景。

## 部署

- **推荐**：把本目录托管发布为公开 HTTPS 网址。云端存档依赖域名匹配，站点必须发布在应用自己的域名上才连得通数据平面。
- **GitHub Pages**：可以作为纯静态镜像，页面能开、本地练习能用，但因为域名不同，**云端存档不可用**。本仓库不内置自动部署工作流，避免 push 触发远程 Actions。

## 回忆录与复习方式

题目带 `grade` / `term`，当前年级在「回忆录」页可改（默认 3 年级上）。判定规则是**「题的年级 < 当前年级」→ 自动归入回忆录**：升到 4、5、6 年级时不需要迁移、不需要导入，原来的题目和旧错题自然沉淀进去。历史错题在回忆录里排最前，连对 2 次才毕业。

| 方式 | 规则 |
|---|---|
| 重点复习 | 未毕业错题优先 + 掌握度低于 60 的知识点 |
| 全面复习 | 按单元 / 年级均衡轮转，可只练本学期或只练回忆录 |
| 专项复习 | 按知识点挑，范围可选「全部年级 / 本学期 / 回忆录」 |
| 期中冲刺 | 默认第 1–4 单元，10 题 |
| 期末冲刺 | 默认全册 8 单元，14 题 |

考试范围里的单元可点选增删（按学校实际进度调整）；交卷后给正确率、错因分布、薄弱知识点与「建议专项」，可直接跳去练那个专项。

**过往题库**：当前内置 1–2 年级原创基础题 22 道（拼音、笔画、量词、形近字、的地得、标点、古诗）。4/5/6 年级题库暂空，机制已就位，届时往 `js/curriculum.js` 加题即可。

## 已知限制

- 题库共 241 道原创题：三上 219 道（26 课 × 6 维度生成 168 道 + 原有 51 道）、一、二年级 22 道。增补只需改 `js/bank-data.js` 的按课素材。
- 未接入汉字笔顺动画与拼音库；如引入需按 NOTICE.md 登记许可。
- 不含登录账号体系（按本地档案区分使用者）、排行榜、AI 出题。
